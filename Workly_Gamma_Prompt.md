## Slide 3: About Workly & Problem Statement

What is Workly?
- A web platform that helps job seekers and recruiters
- Automates resume parsing, job matching and resume building

Problem
- Screening resumes manually takes too much time
- No single platform for both recruiter and job seeker needs

Solution
- AI-powered resume parsing extracts skills and experience automatically
- Smart job matching ranks candidates based on relevance

## Slide 4: Features

For Recruiters
- Upload resumes in PDF, DOCX or TXT format
- Auto-extract skills, education and experience
- Match candidates to job descriptions with relevance scores
- AI chatbot to search candidates in plain English
- Manage hiring sessions and track candidates

For Job Seekers
- Search and apply for jobs with keyword and location filters
- AI Resume Builder with 7 professional templates
- Switch between 1-column and 2-column layouts
- Live ATS compatibility score while editing
- Download resume as a professional PDF
- Track application status with notifications

Developer API Portal
- REST API access for resume parsing and matching
- API key management and usage analytics
- Subscription plans with Razorpay billing

## Slide 5: Tech Stack

Frontend
- React 18 + Vite
- Tailwind CSS
- Zustand for state management
- Recharts for charts
- Framer Motion for animations

Backend
- Python + Django REST Framework
- Celery + Redis for background tasks
- JWT authentication

Database & AI
- PostgreSQL (Supabase)
- Google Gemini API for AI features
- ChromaDB for semantic search
- ReportLab for PDF generation
