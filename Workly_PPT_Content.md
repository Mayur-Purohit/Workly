---

### ❓ What is Workly?
- 🤖 An **AI-powered recruitment platform**
- 🔗 Connects **job seekers** and **recruiters** using smart agents

## 🎨 PPT Design Rules & Best Practices

### ✅ DO's
| # | Rule |
|:--|:-----|
| 1 | Use **dark background** (`#0F172A`) with white text |
| 2 | Keep **max 6 bullets** per slide |
| 3 | Use **icons/emojis** before every bullet |
| 4 | Use **one font family** (Inter or Montserrat) |
| 5 | Add **subtle gradient accents** for section headers |
| 6 | Use **cards/boxes** to group related content |
| 7 | Keep text **under 20 words** per bullet |
| 8 | Use **visual hierarchy** — big title, medium subtitle, small body |
| 9 | Add **team photos** on introduction slide |
| 10 | Use **consistent color palette** throughout |

### ❌ DON'Ts
| # | Avoid |
|:--|:------|
| 1 | ❌ Don't write **paragraphs** — use bullets only |
| 2 | ❌ Don't use **more than 3 colors** per slide |
| 3 | ❌ Don't use **clip art or low-res images** |
| 4 | ❌ Don't **read directly** from slides while presenting |
| 5 | ❌ Don't use **default PowerPoint themes** — go custom |
| 6 | ❌ Don't use **small font** (minimum 16pt for body) |
| 7 | ❌ Don't overcrowd — **whitespace is your friend** |

### 🎨 Recommended Color Palette

| Element | Color | Hex Code |
|:--------|:------|:---------|
| Background | Dark Navy | `#0F172A` |
| Card Background | Deep Slate | `#1E293B` |
| Primary Accent | Indigo | `#6366F1` |
| Secondary Accent | Cyan | `#06B6D4` |
| Success/Green | Emerald | `#10B981` |
| Warning/Red | Coral | `#EF4444` |
| Text | White | `#FFFFFF` |
| Subtle Text | Gray | `#94A3B8` |

### 🔤 Typography Guide

| Usage | Font | Size | Weight |
|:------|:-----|:-----|:-------|
| Slide Title | Montserrat | 36-40pt | Bold |
| Section Header | Inter | 24-28pt | Semi-Bold |
| Body / Bullets | Inter | 16-18pt | Regular |
| Caption / Note | Inter | 12-14pt | Light |
